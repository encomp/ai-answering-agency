## 4. Demand Triggers & Buyer Psychology

- **Home sale / curb appeal** (strongest): repaint before listing, neutral colors for buyers
  [VERIFIED: multiple painter/realtor sources]; spring listing season drives demand.
- **Exterior weathering** + **interior refresh**: project-driven, quote-seeking (homeowners get 3 quotes).
- **Seasonality**: exterior peaks **mid-March → fall, summer best**; **winter = interior repaints**
  (counter-seasonal work — multiple sources [VERIFIED]) — softer season, not dead season.
Urgency: **moderate (3/5)** — not emergency-driven; the sale is made on speed + trust, not fear.
